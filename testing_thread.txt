Instructions to install the Testing Zip:
Drop Residual.zip into the PortMaster autoinstall folder and open PortMaster.
Keep the device online to download Java 17 and Westonpack if required.

Game Information
Title: Residual
URL: https://www.gog.com/en/game/residual

Instructions:
Own the GOG Windows version 1.4.1. Download its full offline installer and any
accompanying .bin files from your GOG library, install it on Windows, and copy
residual.jar from beside residual.exe in the installation directory.
Put it in the installed residual folder alongside residual.ini.
On muOS: <SD card>/ports/residual/residual.jar.
On R36S: <ports directory>/residual/residual.jar.
The package README includes extraction alternatives and the required checksum.
Game data is not included. Requires compatible 64-bit ARM firmware.

Controls:
D-pad / left stick: Move / navigate
A: Action / confirm
B: Jump / up
X: Inventory
Y: Visor
L1: Inventory
R1: Action / confirm
L2: Visor
R2: Down / descend
Start: O / Options
Select: Pause / back
Start + Select: Exit (save through the game first)
