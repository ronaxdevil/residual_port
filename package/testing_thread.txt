Residual - PortMaster testing
Porter: Pixelforge ports (Ronax)

Game: https://www.gog.com/en/game/residual
Package: Residual.zip (BYO data; attach the built ZIP to this post)

Install:
Update PortMaster, put Residual.zip in its autoinstall folder and open PortMaster.
Stay online for the Java 17 and Westonpack downloads if needed.
Supply residual.jar from your owned Windows build (1.4.1).
Destination: <ports directory>/residual/residual.jar.
On muOS: <SD card>/ports/residual/residual.jar.
Download the full Windows offline installer from your GOG library, install it
on Windows or extract with innoextract, then copy the archive unchanged.
See the installed residual.md for the checksum and manual installation instructions.

Controls:
| Control | Keyboard input / action |
|---|---|
| D-pad up | W |
| D-pad down | S |
| D-pad left | A |
| D-pad right | D |
| A | X / Action / confirm |
| B | W |
| X | TAB |
| Y | V |
| L1 | TAB |
| R1 | X / Action / confirm |
| L2 | V |
| R2 | S |
| Start (hold) | Hotkey modifier |
| Start + X | Delete in the save-slot menu |
| Start + Y | O / Options |
| Select | ESC / Back / pause |
| Left stick | Same directions as the D-pad |
| Select + Start | Exit; save through the game first |

Use the game's default keyboard bindings. Hold Start and press Y for options. Hold Start and press X in the save-slot menu to send Delete; follow the game's deletion prompt for the selected slot. Start alone sends no game key. Select + Start remains the exit shortcut.
